# Security

## Supported versions

Only the live site at oddurs.github.io/common-tools gets fixes.

## Reporting a vulnerability

Report it privately through [GitHub Security Advisories](https://github.com/oddurs/common-tools/security/advisories/new), not in a public issue.

You'll get an acknowledgement within a week. If the report is confirmed, a fix ships in a new release and the advisory is published with credit, unless you'd rather stay anonymous.

This is a static site with no server code or forms. Report anything that would let someone change what the site serves or where its download links point. Vulnerabilities in an app go to that app's repository.
