# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Settings never grows taller than the screen it opens on; a long one scrolls. Under **Open at login** the General section now says “Starts when you log in.”, or what stands in the way, and the Common Tools section carries the family promise: free and open source, forever; nothing leaves your Mac.
- Settings follows the layout shared by every Common Tools app: the same window, width, grouped sections, and footnotes as Common Stats, Common Keys, and Common Bar.

### Added

- A Welcome window on first launch: what Common Glyph does, Open at login, and the Common Tools family.
- An optional update check in Settings › General, off by default. When on, it asks GitHub for the latest release once a day and sends nothing about you or your Mac; a newer version shows as a link under the toggle.
- Any number of glyphs, each its own menu bar item showing an image, an animated GIF, an emoji, or a piece of text.
- A Settings window in the Common Tools layout: a preview of every glyph, the list of glyphs to show, hide, duplicate, and delete, **General** with **Open at login**, and **Common Tools**. Each glyph's editor opens as a sheet: light and dark menu bar previews, a crop editor, rotate and flip, three styles (**Colour**, **Silhouette**, **Ink**), background removal by edge colour or by Vision's subject lift, and size.
- A menu on each glyph, in the style of Common Stats and Common Keys: a card showing the glyph, then actions to edit it, choose or paste an image, add a glyph, or hide this one. Dropping an image onto a glyph replaces its image.
- New glyphs start beside the clock, so a menu bar manager doesn't hide them, and Settings notes any glyph that still can't be seen.
