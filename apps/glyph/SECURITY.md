# Security

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Report it privately through [GitHub Security Advisories](https://github.com/oddurs/common-glyph/security/advisories/new), not in a public issue.

You'll get an acknowledgement within a week. If the report is confirmed, a fix ships in a new release and the advisory is published with credit, unless you'd rather stay anonymous.

Common Glyph runs unprivileged, asks for no permissions, and makes no network connections. It reads only the images you choose, paste, or drop, and keeps a copy of the current one in its Application Support folder. Reports about how it decodes images are especially welcome.
